# Appendix C — Criticisms

This appendix is reserved for **critical compositions of the computational object**.

Once the object can be reconstructed without collapsing it into its components, this section will introduce structures for deliberately **challenging, inverting, observing, and controlling** it.

These will include compositions involving:

- **Observers**
- **Inverters**
- **Oracles**
- **Godheads**

Their purpose is not to define Oblivious Compute, but to provide machinery with which its assumptions, boundaries, and behavior can be stressed from inside the model.

The definitions are intentionally withheld here. Introduced too early, the components are easily mistaken for the computational object they are meant to interrogate.

***The object must be seen before it can be torn apart.***
