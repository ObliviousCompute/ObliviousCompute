# Theory

This section contains the theoretical foundation of Oblivious Compute.

The papers are intended to be read sequentially, as each introduces a conceptual framework that the next builds upon.

## Geometry

[**`Computational Block`**](./Geometry.md) Introduces the geometric foundation of history-independent computation and the idea that the present alone can be sufficient.

## Holography

[**`The Holerith Holograph`**](./Holography.md) Explores shared state as a distributed holograph maintained through local representation rather than centralized ownership.

## Admissibility

[**`Lynchpin`**](./Admissibility.md) Introduces admissibility as the mechanism through which independent local evaluation produces coherent shared progression.

## Note

Throughout these papers, terms such as *geometry*, *holography*, *resonance*, and *crystalline* are used as conceptual analogies for informational structure rather than physical phenomena. They are intended to provide intuition for abstract computational relationships, not to describe physical processes.
